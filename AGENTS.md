# AGENTS.md

## Работа по плану

- Двигаемся по `PLAN.md`: берём задачи только из своего трека (A — Backend, B — AI-слой, C — Frontend).
- Выполненные пункты сразу отмечаем: `- [ ]` → `- [x]`. Не накапливать пачкой.
- Если задачи нет в плане, но она нужна — сначала дописать её в `PLAN.md` (в свой трек или новый), потом делать.
- Если пункт оказался ненужным — не удалять, а пометить `~~зачёркнуто~~` + краткая причина.
- Маркеры M0–M4 отмечаются только после фактической проверки, не по намерению.
- Контракты API из `PLAN.md` меняются только с обновлением самого плана в том же коммите.
- Архитектурные решения сверяем с `ARCHITECTURE.md`; отступления — сначала в документ, потом в код.

## Стек и запуск

- Laravel 12 + Blade + Tailwind (Vite), SQLite
- Датасет: `docs/case_1/career_quest_dataset/`
- Запуск: `./setup.sh`
